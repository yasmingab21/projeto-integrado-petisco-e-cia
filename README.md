# Petiscos & Cia

O Petiscos & Cia é um sistema desenvolvido como parte do Projeto Integrado de Análise e Desenvolvimento de Sistemas. O projeto tem como objetivo auxiliar no cadastro de pets e no controle de produtos do estoque de um estabelecimento. O sistema permite cadastrar informações dos pets, como nome, espécie, raça e idade, além de registrar produtos, suas datas de validade, preços por quilograma e quantidade disponível em estoque.
Também é possível consultar a lista de pets cadastrados e gerar uma análise dos produtos, verificando a quantidade de dias restantes até a validade, o valor total do estoque e a situação de cada produto. De acordo com a proximidade da data de validade, o sistema também apresenta sugestões de descontos. O projeto foi desenvolvido em Java utilizando conceitos de Lógica de Programação e Programação Orientada a Objetos, incluindo classes, objetos, encapsulamento, construtores, métodos, estruturas condicionais, estruturas de repetição, arrays e manipulação de datas.
